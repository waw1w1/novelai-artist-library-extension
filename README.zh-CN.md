# NovelAI 提示词图库

[English](README.md) | [简体中文](README.zh-CN.md)

一个用于 NovelAI 图片生成页面的本地图片提示词图库。扩展会在 NovelAI 页面右下角添加图库面板，让你通过图片快速管理和复用画师串与角色 tag。

它可以作为 Microsoft Edge 解压缩扩展直接运行，不需要构建，也不需要额外的本地程序。图片和提示词保存在你自己选择的本地文件夹中。

> 本项目为非官方项目，与 NovelAI 官方没有隶属或背书关系。

## 主要功能

- 分别管理“画师串”和“角色”两类图片提示词。
- 点击画师串图片，将提示词添加到 NovelAI 主提示词最前面。
- 点击角色图片，将角色 tag 复制到系统剪贴板。
- 支持选择本地文件，也支持将 NovelAI 当前图片或历史图片直接拖入面板。
- 网页图片只有拖到插件面板时才会被导入；拖到其他区域仍由 NovelAI 正常处理。
- 按原始字节保存图片，不重编码，并保留原文件已有的 PNG/WebP metadata。
- 使用 SHA-256 检查图片写入前后是否一致。
- 支持收藏置顶、分区排序、改名、切换分类、编辑提示词和删除条目。
- 支持紧凑面板和展开图库。
- 可以用 `−` 将面板收束成很小的悬浮图标，并自由拖动普通面板和小图标。
- 普通面板与小图标的位置会跨页面刷新和浏览器重启保留。
- 界面默认使用英文，可在扩展设置中即时切换英文和简体中文。
- 使用懒加载、并发限制和 LRU 缓存，避免一次读取整个图库。

## 使用条件

- Windows 桌面版 Microsoft Edge。
- 可以访问并登录 [NovelAI](https://novelai.net/) 图片生成页面。
- Releases 安装包或通过 Git 获取的本仓库代码。
- 一个用于保存图库的本地文件夹。

## 安装方法

本项目通过 Edge 的“加载解压缩的扩展”功能安装。可以选择 Releases 安装包或 Git clone 两种方式。

> **不能直接选择 ZIP 文件。** “加载解压缩的扩展”要求选择一个已经解压、并且根目录直接包含 `manifest.json` 的文件夹。

### 方式一：从 Releases 安装（推荐）

1. 打开项目的 [Releases 页面](https://github.com/waw1w1/novelai-artist-library-extension/releases)。
2. 进入最新版本，在 Assets 中下载名称类似下面的安装包：

   ```text
   novelai-prompt-gallery-v0.1.0-edge.zip
   ```

3. 右键下载的 ZIP，选择“全部解压缩”。
4. 打开解压后的文件夹，确认 `manifest.json` 直接位于该文件夹中。
5. Edge 要求选择解压缩扩展目录时，选择这个文件夹。

Releases 安装包只包含扩展运行需要的文件，压缩包根目录已经按照“加载解压缩的扩展”的要求整理好。

### 方式二：使用 Git clone 安装

运行：

```powershell
git clone https://github.com/waw1w1/novelai-artist-library-extension.git
cd novelai-artist-library-extension
```

扩展位于仓库的 `extension` 子目录中。Edge 要求选择扩展目录时，应选择这个 `extension` 文件夹。

### 在 Edge 中加载准备好的目录

1. 在 Edge 地址栏打开：

   ```text
   edge://extensions/
   ```

2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 根据安装方式选择正确的文件夹：

   - Releases 安装：选择解压后直接包含 `manifest.json` 的文件夹。
   - Git 安装：选择 `novelai-artist-library-extension/extension`。

   > 必须选择文件夹本身，不能选择 ZIP、仓库根目录或单独的 `manifest.json` 文件。

5. 确认扩展列表中出现“NovelAI 提示词图库”。
6. 打开或刷新：

   ```text
   https://novelai.net/image
   ```

7. 页面右下角出现图库面板，即表示安装成功。

如果没有显示面板，请在 `edge://extensions/` 中对扩展点击“重新加载”，然后刷新 NovelAI 页面。

## 首次设置数据目录

扩展必须获得一个由用户授权的本地文件夹，用于保存图片和图库清单。

1. 点击面板右上角的齿轮；也可以点击 Edge 工具栏中的扩展图标。
2. 使用设置页顶部的“语言”选项，可以在 English 和简体中文之间即时切换。切换会同步应用到所有已经打开的图库面板，并在浏览器重启后继续保留。
3. 在设置页点击“选择数据目录”。
4. 在 Windows 文件夹选择窗口中选择一个文件夹。

建议新建例如 `NovelAI-Gallery` 的独立文件夹。通过 Git 获取仓库时，也可以使用被忽略的 `data` 文件夹。不要选择 `extension` 文件夹。

5. Edge 询问权限时允许读写。
6. 等待设置页显示目录“可读写”。
7. 返回 NovelAI 页面，必要时刷新一次。

目录选择和授权必须由用户亲自确认，这是 Edge 的安全限制。扩展不能根据本机绝对路径静默获得目录权限。

## 数据目录结构

扩展会在所选目录中建立：

```text
所选文件夹/
├─ library.json   # 提示词、分类、收藏、排序和面板状态
└─ images/        # 原始图片文件
```

备份时请复制整个文件夹。迁移到其他电脑时，复制整个文件夹并在新电脑的设置页重新选择它即可。卸载扩展不会主动删除该目录。

## 导入图片

### 从电脑选择

1. 点击面板右上角的 `＋`。
2. 选择一张或多张图片。
3. 为每张图片选择“画师串”或“角色”。
4. 检查名称和插件保存的提示词。
5. 点击“保存”。

也可以从 Windows 资源管理器把图片直接拖进面板。

### 从 NovelAI 页面拖入

可以把以下图片直接拖入插件面板：

- 中间显示的当前生成图片；
- 历史记录中的图片。

只有鼠标落点位于插件面板内时，扩展才会接管拖放。拖到 NovelAI 主画布、历史区或页面其他位置时，仍由 NovelAI 自己处理。

对于网页图片，扩展会读取原始图片响应，而不是使用 Canvas 截图重编码。如果图片地址已经失效、登录状态失效或浏览器禁止读取，面板会显示错误。此时可以先把图片保存到电脑，再使用 `＋` 导入。

## 保存提示词

导入编辑器可以显示：

- 当前 NovelAI 主提示词；
- 当前角色提示词；
- 从图片 metadata 中识别到的提示词；
- SHA-256 摘要。

提示词来源遵循严格的优先级：

1. 如果图片包含可识别的 **NovelAI metadata**，插件提示词只从图片内置 metadata 中获取，不读取当前网页提示词作为替代。
2. 只有图片不包含可识别的 NovelAI metadata 时，才会把当前 NovelAI 页面提示词作为回退来源。

如果检测到 NovelAI metadata，但其中没有可识别的正向提示词，扩展会保留空白供用户检查，不会静默混入当前网页内容。编辑弹窗会明确标注“优先来源：图片 metadata”或“回退来源：当前页面”。无 metadata 时的提示文案为：

> 未检测到可识别的 NovelAI 图片 metadata，已将当前 NovelAI 页面提示词作为回退来源。

快照中的“【主提示词】”“【角色 1】”等内容只是展示标题，不会作为真正提示词保存。

点击“填入下方”时：

- 用途为“画师串”：只填入当前主提示词。
- 用途为“角色”且只有一个角色提示词：只填入该角色提示词。
- 当前存在多个角色：扩展不会自动合并，需要手动复制所需角色段落。

以后点击卡片时，实际使用的是“插件保存的提示词”字段。

## 使用图库

### 画师串

进入“画师串”分类并点击卡片，保存的画师串会添加到当前可见的 NovelAI 主提示词最前面。如果相同内容已经位于开头，扩展不会重复添加。

### 角色

进入“角色”分类并点击卡片，保存的角色 tag 会复制到系统剪贴板，然后可以粘贴到 NovelAI 对应的角色提示词框。

### 收藏和排序

- 点击爱心可以收藏置顶或取消收藏。
- 收藏区和普通区分别排序。
- 可以在同一分区内拖动卡片改变顺序。
- 跨越收藏区和普通区的排序会被拒绝。

### 编辑

点击卡片右上角的铅笔按钮，可以修改分类、显示名称和保存的提示词。编辑只修改 `library.json`，不会修改或重新编码图片。

### 删除

点击卡片上的红色 `×` 按钮会先打开确认弹窗。确认后，扩展会从 `library.json`、排序列表和 `images/` 文件夹中删除对应条目与原图。

删除操作无法通过扩展撤销。如果以后可能还需要该图片，请先备份数据目录。

### 把原图拖回 NovelAI

把图库卡片拖到 NovelAI 的图片接收区域，可以将保存的原始文件重新交给页面。文件原本具有的 metadata 会继续保留。

### 收束和移动面板

- 点击展开按钮左边的 `−`，可以把图库收束成一个很小的 `✦` 悬浮图标。
- 点击小图标可以恢复普通面板。
- 直接拖动小图标即可改变图标位置。
- 在普通面板标题栏的空白区域拖动，可以改变面板位置。
- 展开后的大面板固定居中，不能拖动。
- 普通面板和小图标分别保存自己的位置，刷新页面或关闭浏览器后不会失效。

需要恢复默认右下角位置时，打开扩展设置并点击“重置面板位置”。该操作也会退出最小化和展开状态，恢复普通面板。

## 面板按钮

| 按钮 | 作用 |
| --- | --- |
| `＋` | 从电脑导入图片 |
| 齿轮 | 打开数据目录设置 |
| `−` | 将面板收束成悬浮小图标 |
| 展开图标 | 切换紧凑面板和展开图库 |
| 爱心 | 收藏或取消收藏 |
| 铅笔 | 编辑分类、名称和提示词 |
| 红色 `×` | 永久删除条目及本地原图 |

## 图片和 metadata

- 支持 PNG、JPEG、WebP、GIF 和 AVIF。
- 单张图片最大 32 MiB。
- 图片不会为了生成缩略图而被重编码。
- 每次写入图片后都会复验 SHA-256。
- 因为保留原始文件字节，源文件已有的 metadata 也会保留。
- 导入时，可识别的 NovelAI metadata 始终优先于网页实时提示词。
- 截图、剪贴板图片或经过转换的文件可能本来就没有生成 metadata，扩展无法恢复不存在的信息。
- 异常巨大的 metadata 会被标记为内容过大未解析，但原图仍可按原始字节保存。

## 更新扩展

如果通过 Releases 安装，请下载新版本并覆盖解压到原来的扩展目录，然后在 Edge 中点击“重新加载”。保持目录不变可以避免解压缩扩展的身份无故变化。如果改为从另一个目录加载，Edge 可能把它识别为新的解压缩扩展，并要求重新选择数据目录；已有图库文件不会被删除。

如果通过 Git 安装，在仓库目录运行：

```powershell
cd novelai-artist-library-extension
git pull
```

文件更新后：

1. 打开 `edge://extensions/`。
2. 找到“NovelAI 提示词图库”。
3. 点击“重新加载”。
4. 刷新已经打开的 NovelAI 页面。

更新扩展代码不会删除数据目录中的图库。

## 常见问题

### 页面没有显示图库面板

- 确认当前地址是 `https://novelai.net/image` 或其子路径。
- 确认扩展已启用。
- 重新加载扩展并刷新 NovelAI。
- 如果 Edge 提示站点权限发生变化，请允许扩展访问 NovelAI。
- 如果面板或小图标被移动到了不方便的位置，请在扩展设置中点击“重置面板位置”。

### 数据目录需要重新授权

浏览器重启、目录移动或权限变化后，Edge 可能暂停目录访问。进入设置页点击“重新授权”。如果目录已经移动或删除，请重新选择目录。

### NovelAI 网页图片拖入面板没有反应

- 确保鼠标落点位于面板内，并出现导入提示。
- 等待历史原图加载完成后再拖动。
- 检查 NovelAI 登录状态是否有效。
- 重新加载扩展并刷新 NovelAI 页面。
- 如果网页图片地址已失效，先保存到电脑，再使用 `＋` 导入。

### 点击画师串后没有写入提示词

- 确认当前位于图片生成页面。
- 切换回 NovelAI 主 Prompt 页签后重试。
- 打开卡片编辑器，确认已经保存提示词。
- 如果 NovelAI 最近更新过页面，尝试重新加载扩展并刷新页面。

### 点击角色后没有复制

保持页面位于前台，并允许 Edge 使用剪贴板。也可以从卡片编辑器中手动复制保存的 tag。

### 可以手动编辑 `library.json` 吗

不建议在扩展运行时手动修改。无效 JSON、重复 ID 或错误排序可能导致图库无法读取。修改前请备份数据目录，并关闭相关 NovelAI 页面。

## 隐私与权限

- 图片和提示词保存在用户选择的本地文件夹中。
- 内容脚本只会在 NovelAI 网站加载。
- NovelAI 子域名权限用于读取拖入面板的网页原图。
- 剪贴板写入权限用于复制角色 tag。
- 扩展没有云同步功能，不会主动把本地图库上传到额外服务。

## 开发与测试

正式扩展位于 `extension/`，不需要构建。

在项目根目录运行：

```powershell
npm test
```

回归测试覆盖图库数据、排序、原图字节、metadata 解析、请求校验和拖放边界。

## 项目定位

本扩展专注于：

1. 使用图片作为提示词的视觉索引；
2. 在本地保留原图和已有 metadata；
3. 快速插入画师串或复制角色 tag。

它不会替代 NovelAI 自带的 Prompt Chunks、账号同步或图片历史功能。
